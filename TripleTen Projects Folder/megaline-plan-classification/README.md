# 📊 Sprint 7 — Megaline Plan Recommendation Project

## 🎯 Project Goal
Build a machine‑learning model that recommends one of Megaline’s two mobile plans — **Smart** or **Ultra** — based on subscriber usage patterns.

## 🧠 Dataset
The dataset includes monthly metrics for each user:
- Number of calls
- Total minutes
- Number of messages
- Internet traffic (MB)

## ⚙️ Approach
- Split data into training, validation, and test sets.
- Trained and evaluated three classification models:
  - Decision Tree  
  - Random Forest  
  - Logistic Regression
- Tuned hyperparameters and compared accuracy scores.

## 🏆 Results
- **Random Forest** achieved the highest accuracy and stability.
- Final model accuracy: **≥ 0.875**, meeting project requirements.
- Insights help Megaline guide users toward the most suitable plan.

## 🧰 Tools & Technologies
- Python (Pandas, NumPy, Scikit‑learn, Matplotlib)
- Jupyter Notebook
- Git & GitHub for version control

## 📈 Key Takeaways
- Learned how to apply classification algorithms to real business data.
- Practiced model evaluation and hyperparameter tuning.
- Strengthened understanding of predictive analytics for decision support.
