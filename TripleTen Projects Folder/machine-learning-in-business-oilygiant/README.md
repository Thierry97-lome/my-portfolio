# Machine Learning in Business — OilyGiant Project
# 📊 Project Overview

This project applies predictive modeling, profit simulation, and bootstrapping to identify the most profitable oil exploration region for OilyGiant.  
It demonstrates how data science supports business decisions through risk‑aware analysis.

## Key Highlights
- Built a linear regression model to predict oil reserves
  
- Simulated profit outcomes using bootstrapping
  
- Evaluated risk and uncertainty across three regions
  
- Recommended **Region 2** as the most stable and profitable investment
  

## Tools & Technologies
- Python (pandas, scikit‑learn, NumPy)
  
- Jupyter Notebook
  
- Statistical bootstrapping and confidence interval analysis
