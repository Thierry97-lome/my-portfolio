## 📁 Featured Projects

### 🏆 Capstone
**[Interconnect — Customer Churn Prediction](./TripleTen%20Projects%20Folder/interconnect-churn-prediction)**
Predicted telecom customer churn using a rigorously validated Random Forest model (train/validation/test separation, leak-free pipelines, permutation importance). Final test AUC-ROC: **0.8417**.

### 🤖 Machine Learning — Classification & Regression
**[Customer Churn Prediction — Beta Bank](./TripleTen%20Projects%20Folder/customer-churn-prediction)**
Predicted bank customer churn, addressing severe class imbalance via upsampling and class weighting. Best model (Random Forest): F1 = 0.556, AUC-ROC = 0.873.

**[Megaline Plan Recommendation](./TripleTen%20Projects%20Folder/megaline-plan-classification)**
Built a classification model recommending mobile plans (Smart/Ultra) based on subscriber usage, comparing Decision Tree, Random Forest, and Logistic Regression.

**[OilyGiant — Region Selection](./TripleTen%20Projects%20Folder/machine-learning-in-business-oilygiant)**
Used linear regression, profit simulation, and bootstrapping to identify the most profitable oil exploration region under risk constraints.

**[Rusty Bargain — Car Price Prediction](./TripleTen%20Projects%20Folder/car-price-prediction)**
Compared 5 regression models (Linear Regression, Decision Tree, Random Forest, LightGBM, CatBoost) on used car pricing, balancing accuracy against training/prediction speed.

**[Gold Recovery Prediction](./TripleTen%20Projects%20Folder/gold-recovery-prediction)**
Predicted industrial gold recovery efficiency from real mining process data using a custom sMAPE metric and Random Forest regression.

**[Sure Tomorrow Insurance — Multi-Task ML](./TripleTen%20Projects%20Folder/insurance-ml-project)**
Solved four ML tasks for an insurance company: customer similarity (kNN), benefit prediction (classification), benefit regression (built from scratch), and data privacy via matrix obfuscation — with an original analytical proof.

### 📊 Statistical Analysis & EDA
**[Netflix Content Analysis — EDA](./TripleTen%20Projects%20Folder/netflix-eda-project)**
Explored how Netflix's content library evolved over time: catalog growth, Movies vs. TV Shows, genre/rating/country trends.

**[Megaline — Statistical Plan Analysis](./TripleTen%20Projects%20Folder/megaline-plan-analysis)**
Compared Surf vs. Ultimate plan revenue using descriptive statistics and hypothesis testing (t-tests), finding a statistically significant revenue difference (p < 0.001).

**[Video Game Sales Analysis](./TripleTen%20Projects%20Folder/video-game-sales-analysis)**
Analyzed platform, genre, and regional sales trends to identify what drives video game success, with hypothesis testing on user ratings.

### ⏱ Time Series Forecasting
**[Sweet Lift Taxi — Demand Forecasting](./TripleTen%20Projects%20Folder/taxi-demand-forecasting)**
Forecasted hourly taxi demand using seasonal decomposition and lag/rolling-window feature engineering. Best model (CatBoost): RMSE = 42.44, beating the target of 48.

### 🗣 Natural Language Processing
**[IMDB Sentiment Classification](./TripleTen%20Projects%20Folder/imdb-sentiment-classification)**
Built a movie review sentiment classifier for Film Junky Union, comparing 5 approaches (TF-IDF + Logistic Regression/LightGBM, with NLTK and spaCy preprocessing, plus BERT embeddings). Best model: F1 = 0.88, exceeding the 0.85 target.

### 👁 Computer Vision
**[Age Estimation from Photos](./TripleTen%20Projects%20Folder/age-estimation-cv)**
Fine-tuned a ResNet50 model to estimate age from face photos for a retail age-verification use case. Validation MAE: 6.6–7.7 years, meeting the ≤8 year target.
